# Démonstration en cinq minutes

0:00–0:45 — Problème : router des réclamations parmi trois produits financiers. Montrer la source CFPB et préciser que les textes sont anglais, historiques et non vérifiés.

0:45–1:30 — Montrer le schéma Mermaid du README, les partitions et l’empreinte. Expliquer la prévention des doublons et le test réservé.

1:30–2:30 — Lancer Streamlit avec la commande README, entrer une réclamation anglaise. Cliquer Comparer les trois approches. Lire les JSON et sorties brutes. Expliquer qu’un résultat LoRA smoke n’est pas un gain établi. Si adaptateur_full est disponible, le sélectionner pour le second passage.

2:30–3:15 — Importer demo.csv (entrées illustratives), choisir classic, Analyser le CSV et exporter. Ouvrir le CSV exporté. Les libellés produits restent ceux de la source.

3:15–4:15 — Montrer le rapport réel, macro-F1, matrices et JSON invalides. Ne pas masquer les mauvais résultats. Résumés null : indisponibles, aucune annotation de référence inventée. Montrer la grille humaine préparée.

4:15–5:00 — Expliquer W + BA, le masquage de loss sur le prompt, l’environnement CPU, les tests et les limites. Terminer sur ce qui a été exécuté et ce qui reste à explorer, sans prétendre avoir publié sur GitHub ou exécuté Colab.
